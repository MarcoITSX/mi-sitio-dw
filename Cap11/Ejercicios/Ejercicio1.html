Autoevaluación Capítulo 11

11.1

Complete las siguientes oraciones:

a.- Como JavaScript usa objetos para realizar muchas tareas, se conoce por lo común como __________.

Respuesta: lenguaje de programación basado en objetos.

b.- Todos los objetos tienen __________ y exhiben __________.

Respuesta: atributos, comportamientos.

c.- Los métodos del objeto __________ nos permiten realizar muchos cálculos matemáticos comunes.

Respuesta: Math.

d.- Al proceso de invocar (o llamar) al método de un objeto se le conoce como __________.

Respuesta: enviar un mensaje al objeto.

e.- Las literales de cadena o constantes de cadena se escriben como una secuencia de caracteres en __________ o __________.

Respuesta: comillas dobles, comillas sencillas.

f.- Los índices para los caracteres en una cadena empiezan en __________.

Respuesta: 0.

g.- Los métodos __________ y __________ de String buscan la primera y última ocurrencias de una subcadena en un objeto String, respectivamente.

Respuesta: indexOf, lastIndexOf.

h.- Al proceso de dividir una cadena en tokens se le denomina __________.

Respuesta: tokenización.

i.- El procesamiento de fechas y horas puede realizarse con base en la __________ o en el __________ del Estándar de Tiempo Mundial.

Respuesta: zona horaria local de la computadora, Tiempo Universal Coordinado (UTC).

j.- El método __________ de Date recibe como argumento una cadena que representa una fecha y hora, y devuelve el número de milisegundos transcurridos entre la medianoche del 1 de enero de 1970 y la fecha y hora especificadas.

Respuesta: parse.

k.- Las aplicaciones Web pueden usar la propiedad __________ del objeto window para almacenar hasta varios megabytes de datos de cadenas de pares clave/valor en la computadora del usuario y pueden acceder a estos datos a través de sesiones y pestañas del navegador.

Respuesta: localStorage.

l.- Las aplicaciones Web que necesitan acceso a los datos de pares clave/valor para sólo una sesión de navegación y que deben mantener separados esos datos entre varias pestañas pueden usar la propiedad __________ del objeto window.

Respuesta: sessionStorage.

m.- Un selector __________ de CSS3 selecciona el primer hijo de un elemento.

Respuesta: :first-child.

n.- Un selector __________ de CSS3 con el argumento "odd" selecciona los elementos hijos impares y uno con el argumento "even" selecciona los elementos hijos pares.

Respuesta: :nth-child.
