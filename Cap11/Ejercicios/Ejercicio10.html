11.10 - Desglose de un número telefónico

Escriba una aplicación que reciba como entrada un número telefónico como una cadena de la forma (555) 555-5555 o (555)555-5555. La aplicación deberá utilizar el método String split para extraer el código de área como un token, los primeros tres dígitos del número telefónico como otro token y los últimos cuatro dígitos del número telefónico como otro token. Muestre en pantalla el código de área en un campo de texto y el número telefónico de siete dígitos en otro campo de texto.
