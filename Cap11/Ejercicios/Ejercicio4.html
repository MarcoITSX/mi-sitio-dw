11.4 - Redondeo de números con Math.floor

Math.floor se puede usar para redondear un número a un lugar decimal específico. Por ejemplo, la instrucción:

y = Math.floor( x * 10 + 0.5 ) / 10;

redondea x a la posición de las décimas (el primer entero a la derecha del punto decimal). La instrucción:

y = Math.floor( x * 100 + 0.5 ) / 100;

redondea x a la posición de las centésimas (el segundo número a la derecha del punto decimal). Escriba una secuencia de comandos que defina cuatro funciones para redondear un número x de varias formas:

  • a) redondearAEntero( numero )
  • b) redondearADecimas( numero )
  • c) redondearACentesimas( numero )
  • d) redondearAMilesimas( numero )

Para cada lectura, su secuencia de comandos debe mostrar el valor original, el número redondeado al entero más cercano, el número redondeado a la décima más cercana, el número redondeado a la centésima más cercana y el número redondeado a la milésima más cercana.
