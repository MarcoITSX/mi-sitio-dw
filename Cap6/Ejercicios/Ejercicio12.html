Ejercicio 6.12

(Modificación de variables) ¿Cuál de las siguientes instrucciones de JavaScript contiene variables cuyos valores se modifican?

a.- p = i + j + k + 7;
Respuesta: Sí modifica variables. El valor de la variable p se modifica al asignarle el resultado del cálculo de la expresión.

b.- window.alert( "variables cuyos valores se destruyen" );
Respuesta: No modifica variables. Únicamente muestra una cadena de texto literal en un diálogo de alerta.

c.- window.alert( "a = 5" );
Respuesta: No modifica variables. Es una cadena de texto literal dentro de un diálogo de alerta, por lo que no se realiza ninguna asignación a la variable a.

d.- cadenaVal = window.prompt( "Escriba una cadena:" );
Respuesta: Sí modifica variables. El valor de la variable cadenaVal se modifica al asignarle la cadena introducida por el usuario.

Conclusión: Las instrucciones de los incisos a) y d) son las que modifican variables (p y cadenaVal).
