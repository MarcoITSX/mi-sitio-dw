6.5

a.- Indique que una secuencia de comandos calculará el producto de tres enteros [Sugerencia: use texto que ayude a documentar una secuencia de comandos].
// Calcula el producto de tres enteros.

b.- Declare las variables x, y, z y resultado.
var x, y, z, resultado;

c.- Declare las variables xVal, yVal y zVal.
var xVal, yVal, zVal;

d.- Pida al usuario que introduzca el primer valor, lea el valor del usuario y almacénelo en la variable xVal.
xVal = window.prompt( "Escriba el primer entero:", "0" );

e.- Pida al usuario que introduzca el segundo valor, lea el valor del usuario y almacénelo en la variable yVal.
yVal = window.prompt( "Escriba el segundo entero:", "0" );

f.- Pida al usuario que introduzca el tercer valor, lea el valor del usuario y almacénelo en la variable zVal.
zVal = window.prompt( "Escriba el tercer entero:", "0" );

g.- Convierta la cadena xVal en un entero y almacene el resultado en la variable x.
x = parseInt( xVal );

h.- Convierta la cadena yVal en un entero y almacene el resultado en la variable y.
y = parseInt( yVal );

i.- Convierta la cadena zVal en un entero y almacene el resultado en la variable z.
z = parseInt( zVal );

j.- Calcule el producto de los tres enteros contenidos en las variables x, y y z, y asigne el resultado a la variable resultado.
resultado = x * y * z;

k.- Escriba una línea de texto de HTML5 que contenga la cadena "El producto es " seguida del valor de la variable resultado.
document.writeln( "<h1>El producto es " + resultado + "</h1>" );
