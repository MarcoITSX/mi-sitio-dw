Autoevaluación Capítulo 6

6.4

a.- Identifique y corrija los errores en la siguiente instrucción:
if ( c < 7 );
   window.alert( "c es menor que 7" );
Error: No debe haber un punto y coma después del paréntesis derecho de la condición en la instrucción if [2].
Corrección: Elimine el punto y coma después del paréntesis derecho [2]. (Nota: El resultado de este error es que la instrucción de salida se ejecuta siempre, independientemente de si la condición es verdadera o falsa, ya que el punto y coma actúa como una instrucción vacía) [2].

b.- Identifique y corrija los errores en la siguiente instrucción:
if ( c -> 7 )
   window.alert( "c es igual o mayor que 7" );
Error: El operador relacional -> es incorrecto [3].
Corrección: Cambie -> por >= [3].
