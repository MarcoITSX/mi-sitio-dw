Ejercicio 6.19

(Círculo: diámetro, circunferencia y área) Escriba una secuencia de comandos que obtenga del usuario el radio de un círculo y produzca texto de HTML5 que muestre el diámetro, la circunferencia y el área de ese círculo. Use el valor constante 3.14159 para π y las fórmulas: diámetro = 2r, circunferencia = 2πr y área = πr2.
