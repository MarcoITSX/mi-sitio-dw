Ejercicio 6.13

(Evaluación de expresiones algebraicas) Dada la ecuación y = ax3 + 7, ¿cuáles de las siguientes instrucciones de JavaScript son correctas para esta ecuación?

a.- y = a * x * x * x + 7;
Correcta. Evalúa primero las multiplicaciones de izquierda a derecha (a · x · x · x = ax3) y finalmente suma 7.

b.- y = a * x * x * (x + 7);
Incorrecta. Multiplica ax2 por la expresión (x + 7), lo que equivale a ax3 + 7ax2.

c.- y = (a * x) * x * (x + 7);
Incorrecta. Multiplica ax2 por (x + 7), resultando en ax3 + 7ax2.

d.- y = (a * x) * x * x + 7;
Correcta. Los paréntesis agrupan la multiplicación inicial ax, que luego se multiplica por x2 y se le suma 7, dando como resultado ax3 + 7.

e.- y = a * (x * x * x) + 7;
Correcta. Calcula el cubo de x primero dentro del paréntesis (x3), lo multiplica por a y le suma 7.

f.- y = a * x * (x * x + 7);
Incorrecta. Equivale a ax(x2 + 7) = ax3 + 7ax.

Conclusión: Las instrucciones correctas son los incisos a), d) y e).
