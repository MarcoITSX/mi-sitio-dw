Ejercicios Capítulo 9

9.11

Escriba instrucciones que asignen enteros aleatorios a la variable n en los siguientes rangos:

a) 1 ≤ n ≤ 2

Respuesta:

n = Math.floor( 1 + Math.random() * 2 );

b) 1 ≤ n ≤ 100

Respuesta:

n = Math.floor( 1 + Math.random() * 100 );

c) 0 ≤ n ≤ 9

Respuesta:

n = Math.floor( Math.random() * 10 );

d) 1000 ≤ n ≤ 1112

Respuesta:

n = Math.floor( 1000 + Math.random() * 113 );

e) -1 ≤ n ≤ 1

Respuesta:

n = Math.floor( -1 + Math.random() * 3 );

f) -3 ≤ n ≤ 11

Respuesta:

n = Math.floor( -3 + Math.random() * 15 );

Explicación general:

Para generar un entero aleatorio dentro del rango a ≤ n ≤ (a + b - 1), se utiliza la fórmula general:

n = Math.floor( a + Math.random() * b );

donde:

  • a es el valor de desplazamiento (el límite inferior del rango).
  • b es el factor de escala (la cantidad total de números enteros posibles dentro del intervalo, calculado como máx - mín + 1).
