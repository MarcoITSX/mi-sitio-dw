Ejercicios Capítulo 9

9.30

¿Qué hace la siguiente función?

// El parámetro b debe ser entero
// positivo para evitar recursividad infinita
function misterio( a, b )
{
    if ( b == 1 )
        return a;
    else
        return a + misterio( a, b - 1 );
}

Respuesta:

La función misterio( a, b ) calcula el producto o multiplicación entera de dos números (a × b) mediante el uso de sumas sucesivas recursivas.

Explicación del funcionamiento:

  • Caso base (condición de terminación): Cuando b == 1, la función devuelve el valor de a.
  • Paso de recursividad: Si b > 1, la función suma a al resultado devuelto por la llamada recursiva misterio( a, b - 1 ).
  • En efecto, la función suma el valor de a a sí mismo un total de b veces. Por esta razón, el argumento b debe ser un entero positivo (b ≥ 1) para garantizar que el valor se reduzca progresivamente hasta alcanzar el caso base y evitar un ciclo de recursividad infinita.
