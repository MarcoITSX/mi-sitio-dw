9.4

Complete las siguientes oraciones:

a.- El __________ de un identificador es la parte del programa en donde puede usarse.

Respuesta: alcance. [1, 2]

b.- Las tres formas de devolver el control de una función invocada al que la llamó son __________, __________ y __________.

Respuesta: return;, return expresión; y llegar a la llave derecha de cierre de una función (}). [1, 2]

c.- La función __________ se utiliza para producir números aleatorios.

Respuesta: Math.random. [1, 2]

d.- Las variables declaradas en un bloque o en la lista de parámetros de una función son de alcance __________.

Respuesta: local. [1, 2]
