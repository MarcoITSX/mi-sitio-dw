Autoevaluación Capítulo 9

9.5

Localice el error en cada uno de los siguientes segmentos de programa y explique cómo corregirlo: [1]

a.-

method g()
{
   document.writeln( "Dentro del método g" );
}

Error: method no es la palabra clave que se utiliza para comenzar la definición de una función [2].

Corrección: Cambiar method a function [2].

b.-

// Esta función debe devolver la suma de sus argumentos
function suma(x, y)
{
   var resultado;
   resultado = x + y;
}

Error: Se supone que la función debe devolver un valor, pero no es así [2].

Corrección: Eliminar la variable resultado y colocar la instrucción return x + y; en la función, o agregar la instrucción return resultado; al final del cuerpo de la función [2].

c.-

function f( a );
{
   document.writeln( a );
}

Error: El punto y coma después del paréntesis derecho que encierra la lista de parámetros [2].

Corrección: Elimine el punto y coma después del paréntesis derecho de la lista de parámetros [3].
