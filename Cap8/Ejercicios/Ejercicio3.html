Autoevaluación Capítulo 8

8.3

a.- Encuentre el error en el siguiente segmento de código, y explique cómo corregirlo:

x = 1;
while ( x <= 10 ) ;
   ++x;
}

Error: El punto y coma después del encabezado while provoca un ciclo infinito; además falta la llave izquierda de apertura ({) para el bloque del ciclo [1].

Corrección: Reemplazar el punto y coma por una llave izquierda ({), o eliminar tanto el punto y coma (;) como la llave derecha (}) [1].

b.- Encuentre el error en el siguiente segmento de código, y explique cómo corregirlo:

switch ( n )
{
   case 1:
      document.writeln( "El n&uacute;mero es 1" );
   case 2:
      document.writeln( "El n&uacute;mero es 2" );
      break;
   default:
      document.writeln( "El n&uacute;mero no es 1 ni 2" );
      break;
}

Error: Falta una instrucción break en las instrucciones del primer case [1].

Corrección: Agregar una instrucción break; al final de las instrucciones para el primer case [1]. (Cabe mencionar que esta omisión no es necesariamente un error si se desea explícitamente que la instrucción del case 2: se ejecute siempre después de la del case 1:) [1].

c.- El siguiente código debe imprimir los valores 1 a 10. Encuentre el error y explique cómo corregirlo:

n = 1;
while ( n < 10 )
   document.writeln( n++ );

Error: Se está utilizando un operador relacional inadecuado (<) en la condición de continuación del ciclo while, lo que provoca que se impriman solo los números del 1 al 9 [2].

Corrección: Usar <= en vez de < (es decir, n <= 10), o cambiar la condición a n < 11 [2].
