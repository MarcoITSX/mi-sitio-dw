Ejercicios Capítulo 8

8.4

Encuentre el error en cada uno de los siguientes segmentos de código. [Nota: puede haber más de un error].

a.-

For ( x = 100, x >= 1, ++x )
   document.writeln( x );

Errores:

  • La palabra clave For comienza con mayúscula; JavaScript distingue entre mayúsculas y minúsculas y requiere for.
  • Se utilizaron comas (,) en lugar de puntos y comas (;) para separar las tres expresiones del encabezado del ciclo for.
  • Para contar de manera descendente del 100 al 1, la expresión de actualización debe decrementar la variable de control (por ejemplo, --x), en lugar de incrementarla (++x), lo que provocaría un ciclo infinito.

Corrección:

for ( x = 100; x >= 1; --x )
   document.writeln( x );

b.- El siguiente código debe imprimirse sin importar si el valor entero es par o impar:

switch ( valor % 2 )
{
   case 0:
      document.writeln( "Entero par" );
   case 1:
      document.writeln( "Entero impar" );
}

Error: Falta la instrucción break; al final del case 0:. Sin ella, cuando valor % 2 sea 0, se ejecutará la instrucción del case 0: y continuará la ejecución directamente en el case 1:, imprimiendo ambos mensajes ("Entero par" y "Entero impar").

Corrección:

switch ( valor % 2 )
{
   case 0:
      document.writeln( "Entero par" );
      break;
   case 1:
      document.writeln( "Entero impar" );
      break;
}

c.- El siguiente código debe imprimir los enteros impares del 19 al 1:

for ( x = 19; x >= 1; x += 2 )
   document.writeln( x );

Error: La expresión de actualización x += 2 suma 2 en cada iteración en lugar de restarlo. Para contar de manera descendente de 19 a 1 en pasos de 2, debe restar 2 (x -= 2). De lo contrario, la condición x >= 1 siempre será verdadera y se generará un ciclo infinito.

Corrección:

for ( x = 19; x >= 1; x -= 2 )
   document.writeln( x );

d.- El siguiente código debe imprimir los enteros pares del 2 al 100:

contador = 2;
do {
   document.writeln( contador );
   contador += 2;
} While ( contador <= 100 );

Error: La palabra clave While está escrita con la 'W' mayúscula. En JavaScript debe escribirse completamente en minúsculas (while).

Corrección:

contador = 2;
do {
   document.writeln( contador );
   contador += 2;
} while ( contador <= 100 );
