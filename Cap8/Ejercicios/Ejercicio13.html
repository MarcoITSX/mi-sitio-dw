Ejercicios Capítulo 8

8.13

Dada la siguiente instrucción switch:

switch ( k )
{
   case 1:
      break;
   case 2:
   case 3:
      ++k;
      break;
   case 4:
      --k;
      break;
   default:
      k *= 3;
} // fin de switch

x = k;

¿Qué valores se asignan a x cuando k tiene valores de 1, 2, 3, 4 y 10?

Análisis paso a paso:

1. Cuando k = 1:

  • Coincide con case 1:. Se ejecuta la instrucción break; y se sale inmediatamente de la estructura switch.
  • El valor de k no cambia (sigue siendo 1).
  • Resultado: A x se le asigna el valor 1.

2. Cuando k = 2:

  • Coincide con case 2:. Al no haber instrucciones ni break en este caso, cae en cascada (fall-through) hacia el case 3:.
  • Se ejecuta el pre-incremento ++k;, por lo que k incrementa de 2 a 3.
  • Se ejecuta break; y sale del switch.
  • Resultado: A x se le asigna el valor 3.

3. Cuando k = 3:

  • Coincide directamente con case 3:.
  • Se ejecuta el pre-incremento ++k;, por lo que k incrementa de 3 a 4.
  • Se ejecuta break; y sale del switch.
  • Resultado: A x se le asigna el valor 4.

4. Cuando k = 4:

  • Coincide con case 4:.
  • Se ejecuta el pre-decremento --k;, por lo que k decrementa de 4 a 3.
  • Se ejecuta break; y sale del switch.
  • Resultado: A x se le asigna el valor 3.

5. Cuando k = 10:

  • No coincide con ningún case (1, 2, 3 o 4), por lo que pasa a la sección default:.
  • Se ejecuta la asignación multiplicativa k *= 3; (equivalente a 10 * 3), resultando en 30.
  • Resultado: A x se le asigna el valor 30.

Tabla resumen de resultados:

Valor inicial de k Caso ejecutado Valor final de x
1 case 1 1
2 case 2 → case 3 (caída) 3
3 case 3 4
4 case 4 3
10 default 30
