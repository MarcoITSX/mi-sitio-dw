Ejercicios del Capítulo 2

2.13

a.- Atributo. Se utiliza para especificar la anchura de un elemento en píxeles o porcentaje (como en img).

b.- Elemento. Define una celda de datos estándar dentro de una tabla (<td>).

c.- Elemento. Define una celda de encabezado en una tabla (<th>) para títulos de fila o columna.

d.- Atributo. Proporciona un nombre identificador a un componente (como en input) para enviar los datos con su par nombre/valor al servidor.

e.- Elemento. Se utiliza para crear una lista desplegable de opciones en un formulario (<select>).

f.- Atributo. Especifica el tipo de control que se va a insertar (por ejemplo, type="text" o type="submit" dentro de la etiqueta <input>).
