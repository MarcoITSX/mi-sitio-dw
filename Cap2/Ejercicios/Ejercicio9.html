Ejemplos del Capítulo 2

A continuación se presenta una lista de los documentos y ejemplos estudiados en el Capítulo 2: Introducción a HTML5: parte 1. Haga clic en cualquiera de ellos para abrirlos:

  • Figura 2.1: principal.html - Primer ejemplo de HTML5 (párrafo básico).
  • Figura 2.2: encabezado.html - Los elementos de encabezado h1 a h6.
  • Figura 2.3: vinculos.html - Vinculación a páginas web externas (Facebook, Twitter, etc.).

  • Figura 2.11: lista.html - Ejemplo de listas desordenadas y ordenadas anidadas.

  • Figura 2.13: tabla2.html - Ejemplo de tabla compleja con combinación de filas y columnas.
  • Figura 2.14: formulario.html - Creación de un formulario básico para recolectar datos de usuarios.
  • Figura 2.15: formulario2.html - Formulario más complejo con diversos controles de entrada (retroalimentación).
  • Figura 2.16: interna.html - Vinculación interna para facilitar la navegación rápida dentro del mismo documento.
  • Figura 2.17: meta.html - Uso de elementos meta para proveer palabras clave y descripciones a los motores de búsqueda.
