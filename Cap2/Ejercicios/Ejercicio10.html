2.10

a.- Elemento. Es la etiqueta raíz que define el inicio y fin de un documento web.

b.- Atributo. Indica la anchura en píxeles de un elemento (como en img).

c.- Atributo. Especifica la dirección URL de destino dentro de una etiqueta de anclaje a.

d.- Elemento. Representa un salto de línea inmediato (br).

e.- Elemento. Define un encabezado de nivel 3 (h3).

f.- Elemento. Es la etiqueta de anclaje (a) utilizada para crear hipervínculos.

g.- Atributo. Define la ubicación o ruta de origen de un archivo (como en img).
