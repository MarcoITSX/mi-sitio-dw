Ejercicio 3.4

Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué.

a.- Falso. Los navegadores que despliegan el tipo input color como campo de texto requieren que el usuario introduzca un código hexadecimal (por ejemplo, #ADD8E6) en lugar del nombre de un color.

b.- Verdadero. Al hacer clic en el botón de envío, el navegador ejecuta de inmediato las comprobaciones de validación automática del lado del cliente.

c.- Falso. HTML5 valida intrínsecamente la estructura sintáctica de la dirección de correo electrónico (nombre@dominio.com), pero no comprueba si la cuenta existe en la realidad.

d.- Verdadero. El atributo required se puede agregar a cualquiera de los tipos input para exigir que el campo no se envíe vacío.

e.- Verdadero. El atributo autocomplete puede habilitarse o deshabilitarse para el formulario completo o para elementos input individuales específicos.

f.- Verdadero. El elemento time permite especificar una hora, una fecha o ambas.

g.- Falso. El elemento que proporciona una leyenda a la imagen dentro de un elemento <figure> es <figcaption>; el elemento <caption> se utiliza para definir el título de una tabla.

h.- Falso. Es el elemento <summary> el que muestra la leyenda y la flecha; al hacer clic en ella, revela el contenido oculto dentro del elemento <details>.

i.- Verdadero. El elemento footer describe el pie de página que por lo general se coloca en la parte inferior del documento o de una sección.

j.- Falso. El elemento utilizado para resaltar texto en HTML5 es <mark>; el elemento <highlight> no existe en la especificación.
