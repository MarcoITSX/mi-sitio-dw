Ejercicio 7.9

(Identificación de errores) Identifique y corrija los errores en cada uno de los siguientes segmentos de código.

a.-
Error 1: El punto y coma (;) después de la condición del if crea una instrucción vacía y separa la cláusula else.
Error 2: Cierre de comillas incorrecto en la cadena del else.
Código corregido:
if ( edad >= 65 )
    document.writeln( "Edad es mayor o igual que 65" );
else
    document.writeln( "Edad es menor que 65" );

b.-
Error: La variable total no está inicializada a 0, lo que provoca resultados igual a NaN.
Código corregido:
var x = 1, total = 0;
while ( x <= 10 ) {
    total += x;
    ++x;
}

c.-
Error: Faltan las llaves de bloque en el while, dejando fuera la instrucción ++x; y produciendo un ciclo infinito.
Código corregido:
var x = 1;
var total = 0;
while ( x <= 100 ) {
    total += x;
    ++x;
}

d.-
Error: El incremento ++y en lugar de decremento genera un ciclo infinito.
Código corregido:
var y = 5;
while ( y > 0 ) {
    document.writeln( y );
    --y;
}
