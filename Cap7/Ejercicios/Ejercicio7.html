Autoevaluación Capítulo 7

7.7

(Identificación de errores) Identifique y corrija los errores en cada uno de los siguientes segmentos de código:

a.-
while ( c <= 5 ) {
    producto *= c;
    ++c;
Error: Falta la llave derecha de cierre (}) del cuerpo de la instrucción while.
Corrección: Agregar una llave derecha de cierre después de la instrucción ++c;.
Código corregido:
while ( c <= 5 ) {
    producto *= c;
    ++c;
}

b.-
if ( genero == 1 )
    document.writeln( "Mujer" );
else;
    document.writeln( "Hombre" );
Error: El punto y coma (;) después de else produce un error lógico, haciendo que la segunda instrucción de salida se ejecute siempre.
Corrección: Quitar el punto y coma después de else.
Código corregido:
if ( genero == 1 )
    document.writeln( "Mujer" );
else
    document.writeln( "Hombre" );
