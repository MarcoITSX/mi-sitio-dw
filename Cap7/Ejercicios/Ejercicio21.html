Ejercicio 7.21

(Múltiplos de 2 con ciclo infinito) Escriba una secuencia de comandos que produzca texto de HTML5 que siga mostrando en la ventana de comandos los múltiplos del entero 2 (a saber, 2, 4, 8, 16, 32, 64, etcétera). Su ciclo no debe terminar (es decir, debe crear un ciclo infinito). ¿Qué ocurre cuando ejecuta este programa?

¿Qué ocurre cuando se ejecuta este programa?

  1. Bloqueo del navegador: Debido a que el ciclo while ( true ) no posee condición de salida, la secuencia de comandos consume continuamente el hilo principal de ejecución. Esto provoca que la página web se congele y deje de responder a las interacciones del usuario.
  2. Advertencia de script colgado: Los navegadores web detectan que la secuencia de comandos ha entrado en un ciclo infinito y muestran un diálogo de alerta preguntando al usuario si desea detener o finalizar la ejecución del script [2].
  3. Desbordamiento numérico (Infinity): Si el código pudiera ejecutarse indefinidamente, la variable superaría el valor máximo representable en JavaScript (Number.MAX_VALUE ≈ 1.79 × 10308), convirtiéndose en el valor especial Infinity.
