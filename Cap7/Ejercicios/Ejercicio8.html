Autoevaluación Capítulo 7

7.8

(Ciclo infinito) ¿Qué está mal en la siguiente instrucción de repetición while?

while ( z >= 0 )
    suma += z;

Explicación: El valor de la variable z nunca se cambia en el cuerpo de la instrucción while [1]. Por lo tanto, si la condición de continuación de ciclo (z >= 0) es verdadera, se crea un ciclo infinito [1].

Corrección: Para evitar que ocurra un ciclo infinito, z debe decrementarse de manera que en un momento dado se vuelva menor que 0 [1].

Código corregido:
while ( z >= 0 ) {
    suma += z;
    --z;
}
