Ejercicios Capítulo 10

10.13

Etiquete los elementos del arreglo bidimensional de tres por cinco llamado ventas para indicar el orden en el que se deben establecer en cero mediante el siguiente segmento de programa: 

for ( var fila in ventas )
{
   for ( var col in ventas[ fila ] )
   {
      ventas[ fila ][ col ] = 0;
   }
}

Respuesta:

El ciclo for...in externo itera secuencialmente a través de las filas (de la fila 0 a la 2), mientras que el ciclo for...in interno itera a través de las columnas de la fila actual (de la columna 0 a la 4). Por lo tanto, los elementos se asignan en cero por fila (de izquierda a derecha) en el siguiente orden:

Fila \ Columna Columna 0 Columna 1 Columna 2 Columna 3 Columna 4
Fila 0 1º: ventas[ 0 ][ 0 ] 2º: ventas[ 0 ][ 1 ] 3º: ventas[ 0 ][ 2 ] 4º: ventas[ 0 ][ 3 ] 5º: ventas[ 0 ][ 4 ]
Fila 1 6º: ventas[ 1 ][ 0 ] 7º: ventas[ 1 ][ 1 ] 8º: ventas[ 1 ][ 2 ] 9º: ventas[ 1 ][ 3 ] 10º: ventas[ 1 ][ 4 ]
Fila 2 11º: ventas[ 2 ][ 0 ] 12º: ventas[ 2 ][ 1 ] 13º: ventas[ 2 ][ 2 ] 14º: ventas[ 2 ][ 3 ] 15º: ventas[ 2 ][ 4 ]

Secuencia cronológica de asignación (del paso 1 al 15):

  1. ventas[ 0 ][ 0 ] = 0;
  2. ventas[ 0 ][ 1 ] = 0;
  3. ventas[ 0 ][ 2 ] = 0;
  4. ventas[ 0 ][ 3 ] = 0;
  5. ventas[ 0 ][ 4 ] = 0;
  6. ventas[ 1 ][ 0 ] = 0;
  7. ventas[ 1 ][ 1 ] = 0;
  8. ventas[ 1 ][ 2 ] = 0;
  9. ventas[ 1 ][ 3 ] = 0;
  10. ventas[ 1 ][ 4 ] = 0;
  11. ventas[ 2 ][ 0 ] = 0;
  12. ventas[ 2 ][ 1 ] = 0;
  13. ventas[ 2 ][ 2 ] = 0;
  14. ventas[ 2 ][ 3 ] = 0;
  15. ventas[ 2 ][ 4 ] = 0;
